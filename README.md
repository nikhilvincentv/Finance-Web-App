# Expense Tracker

A small expense tracker I wrote in plain HTML, CSS and JavaScript. Pick a category, enter an amount and a date, and it adds a row to the table and updates the running total. Each row has a Delete button that removes it and takes the amount off the total.

Nothing is saved after you refresh the page. It's a simple project from March 2025. Another finance project of mine, with accounts, budgets and CSV import, is [FinanceMe](https://github.com/nikhilvincentv/FinanceMeApp).

## Run it

Open `index.html` in a browser. There's nothing to install.
